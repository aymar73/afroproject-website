Chapter 3

Architecture

The technical heart of the Afro Project: cointegration, VECM, KAN discovery, multi-agent RL, and algorithmic enforcement.

1. Cointegration Analysis

We use the Johansen Trace Test to identify economically synchronized country groups. The test determines whether a linear combination of non-stationary time series is stationary — the statistical equivalent of a long-run equilibrium. 

LR_trace(r) = -T · Σ ln(1 - λ_i)

If the trace statistic exceeds the 95% critical value, we reject the null hypothesis of no cointegration. The result is a set of country groups with a shared long-run equilibrium.

2. VECM & Error Correction Mechanism

The Vector Error Correction Model (VECM) measures how far each country has deviated from its zone's equilibrium. The deviation becomes the trigger for algorithmic enforcement. 

ΔY_t = αβ'Y_{t-1} + Γ₁ΔY_{t-1} + Γ₂ΔY_{t-2} + ε_t

Where:
  α  = adjustment coefficients (speed of convergence)
  β  = cointegrating vector (long-run equilibrium)
  Γ  = short-run coefficients
  ε  = error term

3. KAN as a Discovery Engine

Kolmogorov-Arnold Networks are not just a forecasting tool. They are a discovery engine. Each KAN edge is a learnable 1D function. After training, we can extract the learned functions as symbolic formulas, revealing economic laws that no economist has written down.

For example, KAN might discover that the effect of oil prices on CEMAC inflation is asymmetric: linear on the upside, quadratic on the downside. This is a novel finding that standard linear econometrics cannot detect. 

φ(oil) = 0.1·oil + 0.7·max(0, -oil)²

4. Multi-Agent RL Governance

Each central bank has its own KAN-based RL agent. These agents communicate, negotiate, and learn cooperative policies that balance national sovereignty with zone-wide stability.

The reward function prioritizes:

  • Zone stability — minimize inflation variance
  • Fairness — do not punish countries for external shocks
  • Growth — maximize GDP growth within the zone

5. Algorithmic Enforcement

A Hyperledger Fabric smart contract enforces the ECM penalties automatically. No human override. No political interference. The rules are code.

6. Systemic Safety (VaR Stress Test)

We ran 100,000 Monte Carlo simulations to test whether the Afro could trigger a systemic banking crisis.

Conclusion: Even in total failure, the Afro cannot trigger a systemic banking crisis. The pilot is systemically safe.
