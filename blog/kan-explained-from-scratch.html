KAN Explained From Scratch

October 2026 · 12 min read · Technical Foundations

In the Afro Project, we use a new class of artificial intelligence called Kolmogorov-Arnold Networks (KAN) to govern monetary policy. What is a KAN, and why should a central banker trust it more than a conventional neural network? This essay answers those questions — starting from the simplest possible neural network and building up, one step at a time.

Part 1: The Simplest Neural Network

The Basic Unit: A Neuron

Imagine we want to predict whether someone will buy a house based on two inputs: their salary \( x_1 \), and the house price \( x_2 \).

A single neuron does exactly this:

\[ \text{output} = w_1 \cdot x_1 + w_2 \cdot x_2 + b \]

In plain English: "Multiply salary by some importance \( w_1 \), multiply price by some importance \( w_2 \), add them up, then add a baseline \( b \)."

The \( w \) values are weights — they tell us how important each input is. For example:

\[ \text{output} = 0.8 \cdot \text{salary} - 0.5 \cdot \text{price} + 10 \]

This says: "Salary matters a lot (0.8). Price matters less, and negatively (-0.5). Baseline is 10."

The Problem: Straight Lines Only

A single neuron can only draw straight lines. But the real world is not linear. The relationship between salary and house-buying is not a straight line — it is an S-curve. Below a certain salary, we cannot buy. Above it, we can. In between, it is gradual.

Solution: Stack neurons in layers, and add a nonlinear activation function between them:

\[ \text{output} = \sigma(w_1 x_1 + w_2 x_2 + b) \]

Where \( \sigma \) is something like:

  • Sigmoid: \( \sigma(z) = \frac{1}{1 + e^{-z}} \) — an S-shaped curve
  • ReLU: \( \sigma(z) = \max(0, z) \) — cuts off negatives
  • Tanh: \( \sigma(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} \) — S-shaped, centered at zero

The Full Network: Stacking Layers

A complete neural network is just this, repeated:

\[ h_1 = \sigma(W_1 x + b_1) \] \[ h_2 = \sigma(W_2 h_1 + b_2) \] \[ y = W_3 h_2 + b_3 \]

The structure is: Input → [Linear + Activation] → [Linear + Activation] → Output

What the network learns: The weights \( W \) and biases \( b \). The activation functions \( \sigma \) are fixed — we choose them before training and they never change.

The Key Insight: What KAN Changes

In a standard neural network:

ComponentLearnable?
Weights \( W \)✅ Yes — adjusted during training
Biases \( b \)✅ Yes
Activation functions \( \sigma \)❌ No — fixed before training

Think of it like a recipe: We have a fixed set of cooking techniques (fry, boil, bake) — these are the activation functions. We can adjust the amounts of each ingredient (weights) — but we cannot change the techniques.

KAN changes this. In a KAN, the activation functions themselves are learnable. We are not just adjusting amounts — we are inventing new cooking techniques.

Part 2: What KAN Actually Does

The KAN Neuron

A KAN neuron does not do:

\[ \sigma(w_1 x_1 + w_2 x_2 + b) \]

A KAN neuron does:

\[ \phi_1(x_1) + \phi_2(x_2) \]

Where \( \phi_1 \) and \( \phi_2 \) are learnable functions — not fixed.

Standard NN: Multiply input by weight, add them up, then apply a fixed curve.
KAN: Pass each input through its own learnable curve, then add the results.

What Does "Learnable Function" Mean?

A learnable function is typically represented as a spline — a piecewise polynomial. In plain English: draw a smooth curve by connecting dots with simple curved segments.

Suppose we want to learn the function \( \phi(x) = x^2 \). A spline approximates it like this:

x:    -3   -2   -1    0    1    2    3
φ(x):  9    4    1    0    1    4    9

The spline fits a smooth curve through these points. The positions of the points (called knots) and the curvature between them are the learnable parameters.

In a KAN, each \( \phi \) is a spline. The network learns:

  • Where to place the knots
  • How to curve between them
  • What shape best fits the data

The Kolmogorov-Arnold Theorem: Why This Works

In 1957, Andrey Kolmogorov — one of the greatest mathematicians of the 20th century — proved something remarkable:

Any continuous function of many variables can be written as a sum of continuous functions of one variable.

Mathematically:

\[ f(x_1, x_2, \ldots, x_n) = \sum_{q=1}^{2n+1} \Phi_q\left(\sum_{p=1}^{n} \phi_{q,p}(x_p)\right) \]

In plain English: Any complicated relationship between many inputs can be broken down into simple one-dimensional curves that are added together.

Why this matters for KAN: The theorem guarantees that a KAN with the right structure can represent any continuous function exactly. We are not hoping the network learns something useful — we have a mathematical proof that the solution exists within the architecture.

Part 3: A Concrete Example

The Problem: Learn \( f(x, y) = x^2 + y^2 \)

This is a simple bowl-shaped function. It is not linear, so a single standard neuron cannot learn it exactly.

Standard NN Approach

Input (x, y) → [Linear: w₁x + w₂y + b] → [ReLU] → [Linear] → Output

The network approximates the bowl with many small straight-line pieces. It needs many neurons to get a good approximation.

KAN Approach

Input (x, y) → [φ₁(x) + φ₂(y)] → Output

The network learns:

  • \( \phi_1(x) \approx x^2 \)
  • \( \phi_2(y) \approx y^2 \)

And then adds them. Done.

Why KAN is more efficient: It learns the structure of the problem. The function is a sum of two one-dimensional functions — KAN captures this exactly. A standard NN has to learn it from scratch with many parameters.

Part 4: Why This Matters for the Afro Project

In the Afro Project, we are trying to model economic relationships that follow known laws:

  • Error Correction: Deviations should decay exponentially
  • Peg Stability: Price should oscillate back to target
  • Optimal Control: Policy should follow the Bellman equation

With a standard NN: We throw data at it and hope it learns something. It might. Or it might learn a spurious pattern. We cannot tell.

With a KAN: We throw data at it and inspect the learned functions. If the KAN learns \( \phi(x) \approx e^{-0.5x} \), we know it discovered exponential decay. If it learns \( \phi(x) \approx \sin(x) \), we know it discovered oscillation.

We can read the mind of the network.

This is why KAN is perfect for central banks:

  • They can see the policy rule
  • They can verify it follows economic laws
  • They can trust it because it is not a black box

Part 5: The One-Paragraph Summary

A standard neural network is like a chef who can only use a fixed set of cooking techniques — frying, boiling, baking — but can adjust the amounts of each ingredient. A KAN is like a chef who can invent entirely new cooking techniques. Instead of just tuning numbers (weights), a KAN learns the shapes of the functions themselves. This makes it more powerful, more interpretable, and — crucially for monetary policy — more trustworthy. We can look at a KAN's learned functions and see the economic laws it has discovered. A standard neural network just gives us a number; a KAN gives us a formula.

That is the power we are bringing to African monetary policy.
